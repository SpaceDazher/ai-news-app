# activeContext.md

## Текущий фокус работы

**Задача:** Полное обновление страницы управления источниками (ManageSourcesPage) согласно документации v0.2 и мокапам, с учетом FSD-архитектуры, паттернов и технологических ограничений проекта.

### Краткое описание задачи

- Реализовать современный UI в стиле Notion (sidebar, header, карточки, фильтры, поиск, пагинация, модалка добавления/редактирования, поддержка всех типов источников, статусов, категорий, расписания, аутентификации, тегов, автообновления).
- Все тексты и интерфейс — на русском языке.
- Собственные SVG-иконки для уникального стиля.
- Полная адаптивность, доступность, производительность.
- Интеграция с существующим API и SWR.
- Соответствие мокапу и документации v0.2.

### Ключевые изменения и план

1. **Анализ Memory Bank и кода завершён.**
2. **План изменений:**
   - Использовать FSD: pages/manage-sources/ManageSourcesPage.tsx — точка входа, features/manageSources — бизнес-логика и UI, entities/source — модели и API, shared/icons — SVG-иконки, widgets — Sidebar/Header.
   - Sidebar и Header: доработать/заменить на Notion-style, добавить иконки, подсветку активной страницы, адаптивность.
   - Основная область: грид карточек (SourceContainer), фильтры (табы, категории, поиск, сортировка), пагинация, переключение grid/list.
   - Карточка источника: расширить отображение (описание, категория, теги, статус, расписание, автообновление, действия, бейджи, анимации, glow, glass, toggle, SVG-иконки).
   - Модалка добавления/редактирования: интегрировать AddSourceModal (React Hook Form), поддержка всех полей v0.2, динамика по типу, валидация, аутентификация, категории, теги, расписание, автообновление.
   - State management: SWR + useState/useContext для UI, отказ от redux-thunks в features/manageSources.
   - Error handling: централизованно, все ошибки отображаются в UI, сообщения на русском.
   - Типы: строго по ISource/SourceDataPayload, расширить при необходимости.
   - Стилизация: Tailwind/CSS Modules, анимации, адаптивность, доступность (aria, фокус, alt, контраст).
   - SVG-иконки: создать уникальные для sidebar, статусов, типов источников.
   - Все тексты, подсказки, ошибки — на русском.
   - Соответствие мокапу: визуал, структура, настроение.

3. **Что нужно создать/модифицировать:**
   - widgets/Sidebar/NotionSidebar.tsx, Header/NotionHeader.tsx (или доработать существующие)
   - features/manageSources/ManageSourcesFeature.tsx — интеграция AddSourceModal, SWR-методы, error handling, UI-стейт
   - features/manageSources/ui/SourceContainer.tsx — расширить отображение, добавить toggle, бейджи, расписание, теги, анимации
   - features/manageSources/ui/SourcesList.tsx — улучшить фильтры, сортировку, адаптивность, визуал
   - features/manageSources/ui/AddSourceModal.tsx — доработать при необходимости
   - shared/icons/SourceTypeIcons.tsx, CustomIcons.tsx — добавить SVG-иконки
   - Стили: новые/доработанные CSS Modules/Tailwind для всех компонентов
   - entities/source/hooks/useSources.ts — убедиться в поддержке всех API-операций v0.2

4. **Особое внимание:**
   - Производительность: мемоизация, оптимистичные обновления, пагинация, debounced search
   - Доступность: aria, фокус, alt, контраст, управление с клавиатуры, модалки trap focus
   - Безопасность: не хранить пароли в UI, защищать поля аутентификации
   - Соответствие мокапу и документации v0.2

### Статус реализации

- **Завершено:**
    - Анализ Memory Bank, документации v0.2 и кода.
    - Рефакторинг `ManageSourcesFeature.tsx`: интегрирована `AddSourceModal`, используются SWR-методы (`addSource`, `updateSource`, `deleteSource`, `refreshSource`), реализована обработка ошибок и UI-стейта, добавлена логика `onToggleAutoFetch`.
    - Расширен `SourceContainer.tsx`: отображаются все поля v0.2 (`description`, `category`, `tags`, `status` 'warning', `updateFrequency`, `lastFetched`), добавлен toggle `autoFetch`, улучшены стили (анимация, glow, бейджи), добавлена базовая доступность (aria-атрибуты).
    - Обновлен `SourcesList.tsx`: улучшены фильтры (табы, поиск, категория), сортировка, пагинация, переключение вида grid/list, прокинут `onToggleAutoFetch`, обновлены стили.
    - Обновлены `Sidebar.tsx` и `Header.tsx` до Notion-стиля (collapsible sidebar, иконки-заглушки, поиск, переключатель темы).
    - Обновлены соответствующие CSS Modules (`Sidebar.module.css`, `Header.module.css`, `SourceContainer.module.css`) и CSS (`SourcesList.css`, `AddEditSourceForm.css`).
    - Обновлены типы `ISource` (добавлен статус 'warning').
    - Создан файл `NotionSidebarIcons.tsx` с иконками-заглушками.
    - Обеспечена базовая локализация на русский язык.

- **Инсайты:**
    - Обнаружено расхождение в документации: проект использует `react-router-dom`, а не Next.js App Router. Интеграция выполнена с учетом текущей структуры роутинга.
    - State management для фичи успешно переведен с Redux Thunks на SWR + локальный стейт (`useState`).
